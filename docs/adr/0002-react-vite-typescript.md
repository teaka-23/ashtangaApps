# ADR-0002: Стек — React + Vite + TypeScript

- Статус: принято
- Дата: 2026-11-11

## Контекст

Нужен стек для мобильного веб-UI с компонентной структурой (карточки асан,
шторка деталей, далее — режим практики, избранное). Варианты: React + Vite +
TypeScript, vanilla JS без сборки, Vue/Svelte.

## Решение

React 19 + Vite + TypeScript, строгий режим (конфиги из шаблона Vite).
Сборка — статический бандл (~76 КБ gzip на момент MVP).

## Последствия

Плюсы:

- Типизация данных асан (`src/data/primarySeries.ts`, `src/data/poses.ts`)
  ловит ошибки в структуре на этапе сборки.
- Экосистема React пригодится для следующих фич (роутинг, состояние практики).
- Быстрая сборка и HMR при разработке.

Минусы:

- Слой сборки (node, npm) — издержки по сравнению с vanilla JS.
- Бандл React-доминирует в размере; для одного экрана это избыточно,
  но оправдано планами на рост функциональности.
