# ADR-0003: Иллюстрации асан — SVG-фигурки из координатных данных

- Статус: принято
- Дата: 2026-11-11

## Контекст

Для каждой асаны нужна иллюстрация. Варианты:

1. Фотографии / профессиональные иллюстрации — проблемы с авторскими правами,
   весом, единством стиля.
2. Внешние изображения по ссылкам — зависимость от доступности источников.
3. Собственные векторные схемы.

## Решение

Схематичные фигурки («stick figures»), заданные декларативно координатами
полилиний и головы в `src/data/poses.ts` (сетка 100×100 на фигуру).
Рендер — компонент `src/components/AsanaFigure.tsx`: `<polyline>` для тела,
`<circle>` для головы, пунктирная линия пола. Поза выбирается по ключу
`pose` из данных асаны, поэтому иллюстрацию можно заменить, не трогая данные.

## Последствия

Плюсы:

- Нет растровых ассетов: иллюстрации — часть JS-бандла, ноль сетевых запросов.
- Нет проблем с лицензиями.
- Цвет берётся из текущей темы (currentColor-подход через CSS-классы) —
  автоматическая поддержка светлой/тёмной темы Telegram.
- Единый стиль всех 59 поз.

Минусы (см. техдолг):

- Схемы упрощены: для сложных асан (скрутки, захваты) узнаваемость ниже.
- Варианты A/B/C некоторых асан почти не различаются графически.
- Координаты подобраны вручную, нет валидации читаемости поз.
