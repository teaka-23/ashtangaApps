# ADR-0005: Несколько серий — реестр, роутинг и прогресс

- Статус: принято
- Дата: 2026-11-12

## Контекст

Приложение начиналось с одной (первой) серии. Нужно добавить вторую
(промежуточную / Нади Шодхана) с выбором серии, сохранив поведение первой:
каталог по секциям, шторка, практика с BreathTimer, общий план поз,
прогресс, ru/en, Yoga Mala + `modernAddition`.

Варианты:

1. Отдельные мини-приложения / ветки на серию — дублирование UI и деплоя.
2. Одна «плоская» лента всех асан без выбора серии — путает практикующего.
3. Реестр серий в одном клиенте: UI и практика scoped по `seriesId`.

## Решение

**Реестр** `src/data/series.ts`: `primary` | `intermediate`, у каждой — свои
`asanas` и `sections`. Общие типы — `src/data/types.ts`.

**Контент второй серии** (`intermediateSeries.ts`):

- opening = клоны Сурий + стоя из primary с id `int-<id>` (тот же `pose`);
- уникальные асаны секции `intermediate` (свои id без префикса);
- finishing = клоны завершающей последовательности primary с `int-` id.

Клоны позволяют независимый прогресс и deeplink без коллизий id, при этом
переиспользовать SVG и i18n (lookup через `contentKeyForAsana`, срез `int-`).

**Навигация:**

- `#/` — выбор серии;
- `#/series/:seriesId` — каталог;
- `#/series/:seriesId/asana/:id`, `…/section/:id`, `…/practice[/:id|/continue]`;
- legacy primary `#/asana/:id`, `#/practice…` остаются рабочими.

**Прогресс:** ключ `ashtanga.practice.progress.<seriesId>`; старый
`ashtanga.practice.progress` один раз мигрирует в primary.

Практика, иллюстрации и i18n — те же компоненты, что для первой серии;
меняется только источник массива асан.

## Последствия

Плюсы:

- Один деплой / один Mini App; единый UX для всех серий.
- Прогресс и deeplink не пересекаются между сериями.
- Opening/finishing не дублируются вручную — клоны из primary.
- Третью серию можно добавить в реестр тем же шаблоном.

Минусы:

- Префикс `int-` и content-key lookup — дополнительная договорённость в i18n.
- Legacy-роуты только для primary; новые серии — только через `#/series/…`.
- Состав intermediate (A/B/C/D) частично современный; как и в primary,
  отклонения от Yoga Mala помечены `modernAddition`.
