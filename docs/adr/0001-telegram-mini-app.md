# ADR-0001: Платформа — Telegram Mini App (Web-приложение)

- Статус: superseded → [ADR-0006](0006-dual-platform-tg-vk.md)
- Дата: 2026-11-11
- Обновлено: 2026-11-12

## Контекст

Приложение для практикующих аштанга-йогу: последовательность асан первой серии
с названиями и иллюстрациями. Аудитория — йогины, преимущественно мобильные
пользователи. Нужен быстрый MVP без публикации в App Store / Google Play.

Рассматривались варианты:

1. Telegram Mini App — веб-приложение внутри Telegram.
2. PWA / обычный сайт.
3. Нативное или кроссплатформенное приложение (React Native / Flutter).

## Решение (историческое)

Telegram Mini App. Приложение разрабатывается как обычное веб-приложение и
подключается к боту через BotFather. Интеграция — скрипт
`telegram-web-app.js` и модуль платформы (ready/expand, тема из `themeParams`).

## Статус

С 2026-11-12 платформа расширена: **Telegram + VK Mini Apps** на одном SPA.
Актуальная архитектура — [ADR-0006](0006-dual-platform-tg-vk.md). Telegram-адаптер
сохранён внутри `src/platform/telegram.ts`.
