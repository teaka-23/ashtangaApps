# ADR-0001: Платформа — Telegram Mini App (Web-приложение)

- Статус: принято
- Дата: 2026-11-11

## Контекст

Приложение для практикующих аштанга-йогу: последовательность асан первой серии
с названиями и иллюстрациями. Аудитория — йогины, преимущественно мобильные
пользователи. Нужен быстрый MVP без публикации в App Store / Google Play.

Рассматривались варианты:

1. Telegram Mini App — веб-приложение внутри Telegram.
2. PWA / обычный сайт.
3. Нативное или кроссплатформенное приложение (React Native / Flutter).

## Решение

Telegram Mini App. Приложение разрабатывается как обычное веб-приложение и
подключается к боту через BotFather. Интеграция — скрипт
`telegram-web-app.js` и модуль `src/telegram.ts` (ready/expand, тема из
`themeParams`).

## Последствия

Плюсы:

- Нулевая стоимость распространения: ссылка на бота, нет ревю в сторах.
- Аудитория уже в Telegram; простой шеринг.
- Тема оформления подхватывается из клиента пользователя.
- Приложение остаётся работоспособным как обычный сайт (фолбэк-тема).

Минусы:

- Привязка к платформе Telegram для полноценного UX.
- Ограничения WebView (нет фоновой работы, ограниченный доступ к устройству).
- Нужен HTTPS-хостинг для подключения к боту.
