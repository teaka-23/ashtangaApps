# ADR-0004: Данные асан — статический TypeScript-модуль, без бэкенда

- Статус: принято
- Дата: 2026-11-11

## Контекст

Нужно хранить последовательность первой серии: порядок, названия на санскрите
и русском, виньясы, дришти, заметки. Варианты: бэкенд с API, headless CMS,
статические данные в репозитории.

## Решение

Данные — типизированный массив `PRIMARY_SERIES` в `src/data/primarySeries.ts`.
Бэкенда и базы данных нет; приложение полностью статическое.

## Последствия

Плюсы:

- Ноль инфраструктуры: хостинг — любой статический (GitHub Pages,
  Cloudflare Pages и т.п.).
- Данные версионируются вместе с кодом, правки — через PR.
- Тип `Asana` гарантирует целостность на этапе компиляции.
- Приложение работает офлайн после первой загрузки.

Минусы (см. техдолг):

- Обновление контента требует нового деплоя.
- Пользовательские данные (прогресс) — localStorage / TG CloudStorage / VK Storage
  через `src/platform` (см. ADR-0006); бэкенд не нужен, пока не требуется
  синхронизация между устройствами или между Telegram и VK.
