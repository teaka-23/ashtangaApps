Статус: **36/36 иллюстраций перерисованы; анатомический аудит и SVG-аудит —
0 ERR**. Приёмка владельцем — по новым кадрам.

Источники состава и описаний:

- печатный лист Advanced A (kiselevav.ru) — порядок, дришти (Foot / Hand /
  3rd Eye / Nose / Upward / Side / Face) и визуальные ориентиры;
- AYI, Dr. Ronald Steiner — раздел «3. Serie — Sthira Bhaga»: названия,
  описания и традиционный счёт (`https://ayi.info/ashtanga-yoga/3-serie-sthira-bhaga`);
- указания Ф. Эшер (KPJAYI Certified) — структура виньяс.

## Что исправлено в этой правке

### Порядок и данные

- Восстановлен порядок листа: **Бхайравасана (5) → Скандасана (6) →
  Дурвасана (7) → Урдхва Куккутасана A–C (8–10)**. Раньше УК A стояла
  на 5-м месте, а Скандасана — в самом конце серии.
- Дришти выставлены по печатным подписям листа, а не общим «Вверх/В сторону»:
  Васиштхасана — стопа, Вишвамитрасана — кисть, Кашьяпасана — третий глаз,
  Чакорасана — стопа, Бхайравасана — кисть, Скандасана — нос, Дурвасана —
  вверх, Дигасана A — кисть, Дигасана B — нос, Натараджасана — кисть.
- Переписаны описания всех 36 асан по AYI: в частности, Дигасана A/B
  (стоя на одной ноге, вторая нога далеко назад; руки вперёд / в стороны),
  Уттхита Тривикрамасана (высокий подъём ноги с захватом),
  Натараджасана (прогиб с захватом поднятой назад ноги),
  Хануманасана (наклон вперёд с захватом передней стопы),
  Супта Тривикрамасана (вторая нога на полу, обе кисти держат стопу),
  Дви/Эка Пада Випарита Дандасана (стопы на полу за головой),
  Ганда Бхерундасана (стопы рядом с головой).
- Виранчьясана A1–B3 больше не дубли: A1 — намасте, A2 — замок за спиной,
  A3 — баланс на руках с коленом на плече, B1 — наклон к прямой ноге,
  B2 — более глубокий наклон, B3 — скрутка с захватом большого пальца.

### Иллюстрации: ракурс, шея, руки, стопы

- Единая анатомия во всех 36 кадрах: плечо 26, предплечье 23, бедро 33,
  голень 31, шея 13–15 px. Убраны «короткие руки» (были 19–24 px при
  медиане 50) и длинная шея-стебель.
- **Ракурс.** Лотос на руках (УК A/B) — фронтально; боковые упоры, скрутки,
  прогибы и шпагаты — профиль; Дигасана A/B — стоячий профиль с руками
  вперёд/в стороны; Супта Тривикрамасана — лёжа на спине.
- **Шея и голова.** `headP()` получает **реальный центр плеч торса**, а не
  точку возле головы; шея — короткая капсула радиусом 5 от плеча внутрь
  головы. В балансах (Чакорасана, Бхайравасана, Галавасана, Эка Пада
  Бакасана A) это убрало белый просвет — голова больше не «висит».
- **Руки.** Плечо каждой руки обязано лежать на контуре торса; в Чакорасане
  правое плечо уведено с `[128,118]` на `[118,122]`. Захваты стоп — `wrap`,
  опоры — `flat`.
- **Стопа за головой.** Кашьяпасана, Чакорасана, Бхайравасана, Скандасана,
  Дурвасана, Виранчьясана A1–A3: голень огибает шею, стопа уходит **за
  макушку** (x стопы меньше x головы) и стоит не дальше 24 px от центра
  головы. Раньше стопа оставалась перед лицом или у плеча.
- **Колени.** `aLeg()` автоматически включает `softKnee` при сгибе < ~58°:
  бедро и голень идут двумя капсулами с диском-мыщелком. Острых митер-спиц
  в Пурана Матсьендрасане и Ганда Бхерундасане больше нет.
- **Стопы.** В третьей серии только гладкие `anat*`-контуры: `anatFlat`
  (опора на полу), `anatFlex` (сед, носок вверх), `anatTops` (тыл стопы на
  полу), `anatFree`/`anatLotus` (поднятая/сложенная стопа вдоль голени).
  `anatFlat`/`anatFlex` имеют плоскую подошву и скруглённый подъём;
  `anatFree`/`anatHold` перекрывают пяткой конец голени, поэтому у щиколотки
  нет ни щели, ни острого выступа. В Хануманасане задняя стопа — отдельный
  `anatBack`: компактная стопа, плюсна на полу, подъём к щиколотке, пятка
  сверху; гладкий `smoothClosed`-контур без `L`-углов и заусенцев, без
  длинного тонкого носка-полоски. Нога рисуется плотной и первой,
  передняя — поверх.
  У `anatTops`/`anatFlat`/`anatFlex` голень
  идёт до щиколотки и полностью перекрывается стопой. У опорных стоп
  щиколотка стоит на `y≈162`, а не на линии пола — стопа не схлопывается
  в полоску. Старые
  `flat`/`flex`/`free`/`lotus` и `freeFlex` в третьей серии запрещены
  аудитом. В Дви/Эка Пада Випарита Дандасана обе стопы на полу за головой,
  в Ганда Бхерундасана — рядом с головой.

## Проверки

```bash
npm run illustrations:poses   # анатомия: 144 позы, 0 ERR; advanced — 0 WARN/NOTE
npm run illustrations:audit   # SVG: 144 файла, 0 ERR
npm test                      # 61/61
npm run test:e2e              # 9/9
npx tsc --noEmit
```

Для третьей серии аудит дополнительно проверяет: шея начинается на контуре
торса (`polyDist ≤ 2`), плечо и таз лежат на контуре (9/10 px), `anatFlat`
у пола (ankle y 154–170), нет старых `flat/flex/free/lotus/freeFlex`,
острое колено (< 1.02 рад) обязано идти через `softKnee`, а стопа за
головой — не дальше 24 px от центра головы.

В SVG-аудите у сидячих/лежачих кадров остаются ожидаемые WARN «мелкая
фигура» (высота силуэта < 90 px) — это нормально для седа и пранаямы,
такие же WARN есть в первой и второй сериях.
