# Требования — Ashtanga Mini App

Дата: 2026-11-12. Источник контента: **Yoga Mala** (истина для состава/счёта виньяс).

## Продукт

Telegram Mini App для практикующих: выбор серии (первая / вторая), справочник
асан и режим практики с таймером дыхания. Полностью статический клиент (без бэкенда).

- Первая серия (Йога Чикитса): 61 асана
- Вторая серия (Нади Шодхана): opening + промежуточные + finishing

## Функциональные требования

### Серии

| ID | Требование |
|----|------------|
| F-0 | Экран выбора серии (`#/`); каталог и практика scoped по серии |
| F-0b | Прогресс практики хранится отдельно для каждой серии |
| F-0c | Home: tap карточки → каталог; CTA «Начать практику» (+ «Продолжить») |
| F-0d | Catalog: короткие section chips; BackButton → home (без дублирующего текста) |
| F-0e | Practice: «Выйти» сохраняет прогресс; темп/звук свёрнуты в «Настройки» |

### Каталог

| ID | Требование |
|----|------------|
| F-1 | Список асан по секциям с номером, санскритом, локализованным именем, превью позы, бейджем виньяс |
| F-2 | Асаны вне Yoga Mala помечены `modernAddition` в UI |
| F-3 | Шторка асаны: иллюстрация, имена (в т.ч. деванагари), виньясы/дыхания/дришти, заметка |
| F-4 | В шторке мультикадровых поз — **общая схема виньяс** (все фигуры сразу, с номерами); покадровая навигация снята |
| F-5 | Из шторки можно начать практику с этой асаны |

### Практика

| ID | Требование |
|----|------------|
| F-10 | Режим практики по всей серии (или с выбранной асаны) |
| F-11 | Прогресс: CloudStorage + fallback localStorage; продолжение `#/series/:id/practice/continue` |
| F-12 | Для асан с `breaths` — BreathTimer (вдох/выдох), пауза, авто-переход |
| F-13 | Сурьи с `breaths: 5` — BreathTimer (удержание в Адхо Мукха / круги) |
| F-14 | Мультикадр в практике — **общий план** всей последовательности (без кликов по кадрам); длинная заметка скрыта (есть в шторке) |
| F-15 | Экран практики **без вертикального скролла** (один viewport) |
| F-16 | Показывать заметку/описание асаны в практике |
| F-17 | Темп дыхания: медленно / норма / быстро (сохраняется) |
| F-18 | Звук вдох/выдох (Web Audio), вкл/выкл (сохраняется) |

### Навигация и i18n

| ID | Требование |
|----|------------|
| F-20 | Hash-роуты: `#/`, `#/series/:seriesId`, `#/series/:seriesId/asana/:id`, `#/series/:seriesId/section/:id`, `#/series/:seriesId/practice`, `#/series/:seriesId/practice/:id`, `#/series/:seriesId/practice/continue`; legacy primary `#/asana/:id`, `#/practice…` |
| F-21 | UI на русском; i18n-строки en сохранены, переключатель локали временно скрыт |
| F-22 | Telegram BackButton, haptics |

### Контент / иллюстрации

| ID | Требование |
|----|------------|
| F-30 | Счёт виньяс и состав — по Yoga Mala |
| F-31 | SVG stick-figures: руки/ноги сегментами, торс, дришти; дальняя сторона бледнее; руки цветом ссылки, ноги — текстом; кисть=кружок, стопа=чёрточка |
| F-32 | Силуэт должен читаться: ориентация (стоит/сидит/лежит), где руки и ноги |

## Вне текущего скоупа

- MainButton Telegram
- Кастомная последовательность асан
- Advanced / третья серия
- e2e полный регресс всех асан
- Покадровая навигация (шторка / практика) — снята; модель = общая схема виньяс
- Менять эту модель (схема ↔ один кадр ↔ клик по кадрам) — **только после явного подтверждения владельца**
